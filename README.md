# StealthNotes

Simple sticky notes for Windows 11 x64. Keep notes on top, choose a color, and adjust their opacity.

## Install

Download **StealthNotes-Setup.exe** from [Releases](../../releases), open it, and click **Install**. Launch StealthNotes from the shortcut. Everything you need is included.

## Use

- **+** creates a note. Drag the header to move it; drag an edge to resize.
- **···** opens colors, opacity, and delete.
- **◌** toggles ghost mode. **×** hides the note.
- The tray menu shows or hides all notes and opens hotkey settings.

Ghost notes let clicks pass through. Use these shortcuts to control them:

| Action | Shortcut |
|---|---|
| New note | Ctrl + Alt + N |
| Toggle ghost for a note | Ctrl + Alt + G |
| Toggle ghost for all notes | Ctrl + Alt + Shift + G |
| Show / hide all | Ctrl + Alt + H |
| Adjust opacity | Ctrl + Alt + Up / Down |

Notes save automatically on your computer. No accounts, cloud, or telemetry.

**Please note:** Ghost may not hide notes from every recorder or screen share. This build and installer have not been runtime tested. The unsigned installer may show a Windows warning.
